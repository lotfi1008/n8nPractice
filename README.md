# Prime checker (برنامه تشخیص عدد اول)

This repository now includes a simple Python script main.py that reads a number and
checks whether it is prime.

نحوهٔ اجرا (Persian):

- با اجرای تعاملی:

  python main.py
  (سپس زمانی که پیام نمایش داده شد عدد را وارد کنید، مثلاً 17)

- یا به‌صورت آرگومان خط فرمان:

  python main.py 17

مثال‌ها / Examples:

1) تعاملی:

$ python main.py
یک عدد وارد کنید: 17
عدد 17 اول است.

2) به‌صورت آرگومان:

$ python main.py 18
عدد 18 اول نیست.

توضیحات کوتاه:

- ورودی باید یک عدد صحیح غیرمنفی باشد. در صورت نادرست بودن ورودی، برنامه پیغام خطا نمایش می‌دهد.
- الگوریتم بررسی اول بودن از روش تکراری و بررسی مقسوم‌علیه‌ها تا جذر عدد استفاده می‌کند (عملکرد خوب برای اعداد کوچک و متوسط).

Enjoy!
