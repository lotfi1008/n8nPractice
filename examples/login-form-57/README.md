## LoginForm (کامپوننت فرم لاگین فارسی، RTL)

چه ساخته شد:
- یک کامپوننت React + TypeScript به‌نام `LoginForm` که یک فرم ورود ساده فارسی (راست‌به‌چپ) ارائه می‌دهد.

کامپوننت‌های Dig استفاده‌شده:
- `Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormMessage` (از `@/components/ui/form`)
  - چرا: مدیریت context فرم با react-hook-form، اتصال خودکار ارورها و aria، و ساختار استاندارد فرم‌های دیگ.
- `Input` (از `@/components/ui/input`)
  - چرا: فیلد متن با پشتیبانی از `startContent` برای قرار دادن آیکون آغازین و رفتار RTL/فارسی.
- `PasswordField` (از `@/components/ui/password-field`)
  - چرا: فیلد رمز با دکمهٔ نمایش/پنهان رمز؛ در فرم ورود نوار قدرت و چک‌لیست غیرفعال شده‌اند.
- `Button` (از `@/components/ui/button`)
  - چرا: دکمهٔ ارسال با پشتیبانی از حالت `loading` و `fullWidth`.

آیکون‌های Digche استفاده‌شده (به‌صورت JSX محلی جاسازی‌شده):
- `User` (Linear)
  - چرا: نشان‌دهندهٔ فیلد نام کاربری/ایمیل؛ در `Input` به‌عنوان `startContent` قرار گرفت.
- `Lock Square` (Linear)
  - چرا: نشان‌دهندهٔ فیلد رمز؛ در `PasswordField` به‌عنوان `startContent` قرار گرفت.

دلایل انتخاب‌ها خلاصه:
- ساختار فرم با `Form` و بچه‌های آن تضمین می‌کند که aria و نمایش خطاها به‌درستی کار کنند.
- `Input` و `PasswordField` از قابلیت `startContent`/`endContent` استفاده می‌کنند تا آیکون‌ها بدون تولید HTML سفارشی در محل درست نمایش یابند و جهت RTL حفظ شود.
- `Button` با propهای `loading` و `fullWidth` برای دسترسی و تجربهٔ کاربری مناسب انتخاب شد.

یادآوری نصب:
- این کامپوننت فرض می‌کند که کامپوننت‌های Dig (موجود در شواهد) در پروژه نصب شده و مسیرهای ایمپورت (`@/components/ui/...`) قابل resolve هستند.
- آیکون‌ها به‌صورت JSX داخل همین فایل جاسازی شده‌اند؛ نیازی به نصب جداگانهٔ آیکون نیست.

نکتهٔ فنی:
- فرم از `react-hook-form` برای مدیریت محلی وضعیت استفاده می‌کند و ارسال فرم فقط حالت نمایشی (loading) را شبیه‌سازی می‌کند؛ هیچ فراخوانی شبکه‌ای انجام نمی‌شود.
