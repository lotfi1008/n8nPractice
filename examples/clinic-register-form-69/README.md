## ClinicRegisterForm (کامپوننت ثبت‌نام مطب — RTL، آیکون‌دار)

این فایل یک کامپوننت React + TypeScript ارائه می‌دهد که فرم ثبت‌نام یک مطب را
به زبان فارسی و چیدمان راست‌به‌چپ پیاده‌سازی می‌کند. رفتارها صرفاً
presentation-level هستند و هیچ تماس شبکه یا لاجیک بک‌اند واقعی انجام نمی‌شود.

چه ساخته شد
- `ClinicRegisterForm.tsx`: یک فرم تک‌کامپوننتی برای ثبت‌نام مطب با فیلدهای
  معمول (نام، ایمیل، رمز، تلفن، نام مطب، تخصص، آدرس، شهر، تاریخ، آپلود
  لوگو/آواتار و توضیحات) و چک‌باکس تایید قوانین.
- فرم با `react-hook-form` مدیریت می‌شود و از `Form` و ابزارهای کمکیِ دیگ
  برای اتصالِ خودکار خطا/aria استفاده می‌کند.

کدام کامپوننت‌های Dig استفاده شدند (از evidence.components)
- Form, FormField, FormItem, FormLabel, FormControl, FormMessage, FormDescription
  — برای اتصالِ فرم به react-hook-form و نمایش پیام‌ها.
- Input — فیلدهای متنی، فایل و نمایش ارقام فارسی (faDigits).
- PasswordField — فیلد رمز با دکمهٔ نمایش/پنهان، نوار قدرت و لیست شرط‌ها.
- InputGroup — برای نوارِ آپلود لوگو همراه با دکمهٔ حذف.
- Select, SelectTrigger, SelectValue, SelectContent, SelectItem, SelectLabel,
  SelectGroup — برای انتخاب تخصص و شهر.
- DateField — انتخاب تاریخ با پشتیبانیِ تقویم (شمسی) و ناوبری کیبورد.
- Textarea — فیلد توضیحات (چندخطی) با normalizeArabic پیش‌فرض.
- Avatar — نمایش پیش‌نمایش آواتار/لوگو و حالت fallback.
- Button — دکمهٔ ارسال با حالت loading و دکمهٔ ثانویهٔ پاک‌کردن.
- Checkbox — تایید قوانین.

کدام آیکون‌های Digche (Linear) استفاده شدند
(همهٔ SVGها دقیقاً از evidence.icons در فایل جاسازی شده‌اند):
- user-edit — آیکون فیلد نام
- email — آیکون فیلد ایمیل
- lock-square — آیکون فیلد رمز
- call — آیکون تلفن
- user-add — آیکون نام مطب
- stethoscope — آیکون تخصص
- anchor — آیکون آدرس
- anchor-simple — آیکون شهر
- calendar-pin — آیکون تاریخ
- upload — آیکون آپلود لوگو
- guide — آیکون توضیحات
- user-search — آیکون آواتار پیش‌فرض

چرا هر کدام انتخاب شدند
- هر کامپوننت Dig دقیقاً برای نیاز همان فیلد انتخاب شده تا دسترسی،
  رفتارهای فارسی (faDigits، normalizeArabic)، و تعاملات (reveal/strength برای
  رمز، select typeahead و keyboard navigation، date segments) را به‌صورت
  بومی و سازگار با دیگ فراهم کند.
- آیکون‌ها از Digche Linear انتخاب شدند تا ظاهر همگن و خوانایی آیکون‌ها حفظ شود؛
  SVGها مستقیماً در فایل جاسازی شده‌اند تا وابستگی خارجی نداشته باشد.

نکات نصب
- برای استفاده از این کامپوننت، باید پکیج‌های Dig (کامپوننت‌های ui) که در
  evidence.components آمده‌اند در پروژه نصب/قابل ایمپورت باشند (مسیرها
  مانند `@/components/ui/input` و ... مربوط به ساختار پروژه‌ای است که
  evidence از آن گرفته شده).
- این کامپوننت از react-hook-form استفاده می‌کند؛ بنابراین آن بسته نیز باید
  در پروژه نصب باشد.

محدودیت‌ها
- این فرم فقط presentation-level است: هیچ درخواست شبکه، اعتبارسنجی سرور و
  ذخیره‌سازی واقعی انجام نمی‌دهد. ارسال فرم فقط یک لاگ نمونه در کنسول و یک
  حالت loading شبیه‌سازی‌شده را نشان می‌دهد.
