# PaymentButton

کامپوننت PaymentButton یک دکمهٔ پرداخت راست‌به‌چپ (Persian RTL) ساده و قابل استفاده مجدد است که از کامپوننت رسمی Dig "Button" استفاده می‌کند و آیکون "Credit Card" (نسخهٔ Linear) از Digche را به‌صورت JSX درون فایل قرار می‌دهد.

ویژگی‌ها
- پشتیبانی از حالت loading (با استفاده از پراپ loading که توسط Dig Button پشتیبانی می‌شود).
- دسترس‌پذیری: aria-busy وقتی loading=true است (خود Button آن را می‌گذارد) و می‌توانید ariaLabel را برای صفحه‌خوان پاس دهید.
- نمایش مقدار/واحد پول اختیاری کنار متن دکمه.
- طراحی RTL: با قرار دادن dir="rtl" روی دکمه، آیکون در سمت راست متن قرار می‌گیرد و چیدمان برای فارسی مناسب است.

چه چیزی ساخته شد
- فایل: PaymentButton.tsx
- خروجی: یک React + TypeScript کامپوننت ارائه‌ای (presentation) برای دکمهٔ پرداخت.

کدام Dig کامپوننت‌ها استفاده شدند
- Button (از @/components/ui/button)
  - دلیل انتخاب: کامپوننت رسمی Dig با پشتیبانی از پراپ loading، variant، color، size و مدیریت aria-busy/disabled که تمام نیازهای دکمهٔ پرداخت را برآورده می‌کند.

کدام Digche آیکون‌ها استفاده شدند
- Credit Card (Linear)
  - دلیل انتخاب: آیکونی مناسب برای نشان‌دادن عملیات پرداخت/کارت.
  - توجه: SVG دقیقاً از شواهد (evidence) وارد شده و بدون تغییر داخل یک کامپوننت محلی (CreditCardIcon) قرار گرفته است.

چرا هرکدام انتخاب شدند
- Button: برای استفادهٔ آماده از قابلیت‌های بارگذاری، غیرفعال‌سازی و واریانت/رنگ و نیز هماهنگی با سیستم طراحی.
- Credit Card icon: به‌عنوان نماد پرداخت واضح و آشنا.

نکته نصب
- این کامپوننت بر پایهٔ کامپوننت‌های Dig ساخته شده؛ برای استفاده لازم است پکیج‌ها/کامپوننت‌های Dig که در شواهد آمده‌اند (مثلاً @/components/ui/button) در پروژه نصب و در دسترس باشند.

استفادهٔ نمونه

- به‌صورت ساده:
  <PaymentButton label="پرداخت" amount={120000} currency="تومان" onClick={() => { /* جریان پرداخت */ }} loading={isLoading} />

توضیح: این کامپوننت فقط نمایشی/فرانت‌اند است و هیچ فراخوانی شبکه یا منطق پرداخت واقعی‌ای انجام نمی‌دهد.
